# Sales Call Tracker - Decision Log

- **Decision 1:** The manager reads day-by-day numbers as a fixed 30-bar graph, not through a date picker. The Team page shows a "Day by day" graph for the last 30 days below the calls-by-hour chart, and the person page shows the same graph below the Call Split section — one bar per day, oldest day first, the bar showing the day's dials with the connected calls highlighted as the green segment inside it and the dials count on top, every day present, a day with no calls an empty bar at zero. A specific day like 1 October is read from its bar; no screen asks the manager to pick a date, and a one-day detail screen is not built.
- **Decision 2:** The call log downloads are CSV files, not real Excel (.xlsx) files, and both formats are not offered. A CSV opens in Excel on double-click and needs no new server library. The file carries a UTF-8 BOM so Excel shows every character correctly, and a note holding a comma, a quote, or a line break is escaped inside the file.
- **Decision 3:** Today and yesterday are two separate downloads, not one combined file. The Team page carries no big download buttons — a small download icon sits at the right side of the Today and Yesterday column headings and downloads every salesperson's calls of that day, and a small download icon at the right edge of each day group in every row downloads that one salesperson's calls for that day. Each file holds one day with the salesperson name as a column. The person page carries no download button — its download sits inside the Person Logs screen.
- **Decision 7:** The person page carries a "View logs" button beside the Back link above the KPI cards — the header keeps only the date — which opens the Person Logs screen: every stored call of that person's last 30 days, one row per call, both directions, newest call first, with the "Download logs" button at its heading.
- **Decision 4:** The downloaded logs hold every stored call in both directions — outgoing and answered incoming — with a Direction column to filter by. An outgoing-only download was rejected: incoming talk time already counts in the dashboard minutes, so the log carries the same work the dashboards count.
- **Decision 5:** The day-by-day numbers and the log files are computed from the stored calls at every request, and no pre-aggregated daily table exists. There is no database change: the existing calls data and its indexes already answer every new read, and a stats table was rejected because it could drift away from the stored calls.
- **Decision 6:** A failed download keeps the manager on the page with "Could not download the logs." — no partial file is saved. An ended session returns to the login screen instead of the message.
