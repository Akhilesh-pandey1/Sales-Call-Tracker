# Sales Call Tracker - Decision Log

## Round 1

- **Decision 1:** The Settings tab shows a fifth row — "Notes popup" with a switch on the right, between "Do not track numbers" and "Clear local data". Tapping the row flips the switch; no sub-page opens. The switch is ON by default. ON keeps today's behavior — the notes popup shows before a call when the number has a note. OFF silences only that popup: every call it could have gated — the Scheduled, History, Interested, and Do-not-call rows, the automated lead card, and My List Start Calling — dials straight through. A number with no note dials straight through in both states. The info icon stays on noted rows in both states. The keypad and Call Again never show the popup in either state, and everything after the call starts — recording, the post-call popup, and note overwriting — runs exactly as before.
- **Decision 2:** The Notes popup switch lives on the phone only. It is stored in AsyncStorage like the WhatsApp choice, and its ON-by-default value comes from the app's config — no server change, and a fresh install or a new phone starts ON. The shared pre-call note check reads the switch in the same step it reads the note and shows the popup only when the number has a note and the switch is on; the read happens fresh at every call attempt, so the flip applies from the very next call.
